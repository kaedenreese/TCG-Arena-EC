# TCG Arena Elemental Creatures
Elemental Creatures is copyright 2026 Justin Hartsock. The JSON implementation of the game for TCG Arena is copyright 2026 Kaeden Reese.

This is a gameplay implementation of Elemental Creatures for http://tcg-arena.fr. This is not a standalone way to play the game. If you would like to learn the rules of the game and see our card gallery, please visit http://elementalcreaturestcg.com/.

This 1.0 release contains all the cards from the Alpha Evolved release. Many cards from the First Edition set have been updated and are no longer considered legal for play. There are still some cards that are in First Edition that could technically still be legal, but are currently excluded to facilitate using the new cards, which are balanced against each other. Eventually we may put the legacy cards on here as well.
